# TuringForce Website

The official website for TuringForce - Agentic AI Agent Platform for modern teams.

## Overview

TuringForce lets teams quick-start with pre-built AI agents and easily launch self-service AI agents that deliver interactive, real-time answers across their portfolios — and scale to multi-agent workflows for project management automation.

## Getting Started

### Prerequisites

- Python 3.x (for local development server)
- Modern web browser

### Local Development

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd turingforce-site
   ```

2. Start the local development server:
   ```bash
   npm start
   # or
   python3 -m http.server 8000
   ```

3. Open your browser and navigate to:
   ```
   http://localhost:8000
   ```

### Available Scripts

- `npm start` - Start local development server
- `npm run dev` - Alternative command to start development server
- `npm run serve` - Another alias for the development server
