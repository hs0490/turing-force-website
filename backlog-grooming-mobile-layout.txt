MOBILE BREAKPOINTS:
==================

768px and below:
- Hero content: Single column layout
- Video order: 2 (after text)
- Text order: 1 (before video)
- Video container: Red debug background
- Video element: Green debug background
- All sections: Single column layout

480px and below:
- Hero title: font-size: 1.875rem
- Video min-height: 180px
- Video max-height: 300px
- Container padding: 0 0.75rem

DEBUG INDICATORS:
================

RED CONTAINER (agent-hero-video):
- If visible: Video container is present and positioned
- If not visible: Container has positioning/overflow issues

GREEN ELEMENT (video element):
- If visible: Video element is present and styled
- If not visible: Video element has display issues

BOTH VISIBLE:
- Issue likely with video file or browser compatibility

NEITHER VISIBLE:
- Container has fundamental positioning problems

EXPECTED MOBILE BEHAVIOR:
========================

1. Hero section should be single column
2. Text should appear first (order: 1)
3. Video should appear second (order: 2)
4. Video should have red container background
5. Video should have green element background
6. Video should be fully visible and responsive
7. All sections should stack vertically
8. Text should wrap properly
9. Touch targets should be minimum 44px
10. No horizontal scrolling should occur
